Blum Blum Shub (BBS)

n = p · q, com p ≡ q ≡ 3 (mod 4)  ·  x0 = s² mod n  ·  xi+1 = xi² mod n  ·  biti = xi mod 2

1. Parâmetros

erro

  • ✓ premissa

3. Bits gerados

n = p · q = n

0 bits: 0 zeros e 0 uns

✓ A sequência não volta ao x0 nos passos gerados: o período é maior que a quantidade de bits.

✗ A sequência se repete a cada 0 passos: os bits gerados contêm repetição.
